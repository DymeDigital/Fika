# Finka Brand Design Tokens

Use these tokens when styling components or pages in the Finka project. Reference them via Tailwind v4 CSS variables or Tailwind color classes where appropriate.

## Colors
- **Finka Green**: `#116242` (Tailwind: `var(--color-finka-green)` / `text-finka-green` / `bg-finka-green`)
- **Finka Green Light**: `#178257` (Tailwind: `var(--color-finka-green-light)`)
- **Finka Green Dark**: `#03341E` (Tailwind: `var(--color-finka-green-dark)`)
- **Finka Green Muted**: `#0B4A2F` (Tailwind: `var(--color-finka-green-muted)`)
- **Finka Yellow**: `#F9B603` (Tailwind: `var(--color-finka-yellow)` / `bg-finka-yellow` / `text-finka-yellow`)
- **Finka Yellow Hover**: `#DDA303` (Tailwind: `var(--color-finka-yellow-hover)`)
- **Finka Black**: `#0D0D0D`
- **Finka Charcoal**: `#1A1A1A`
- **Finka Grey 50-800**: Grey shades from `#FAFAF9` to `#3A3A38`
- **Finka White**: `#FAFAF9`

## Typography
- **Sans font**: `'Inter', system-ui, -apple-system, sans-serif`
- **Display font**: `'Poppins', 'Inter', system-ui, -apple-system, sans-serif`

## Spacing & Radius
- **Radius Sm**: `3px`
- **Radius Md**: `5px`
- **Radius Lg**: `8px`

## Transitions
- **Ease Out Expo**: `cubic-bezier(0.16, 1, 0.3, 1)`
