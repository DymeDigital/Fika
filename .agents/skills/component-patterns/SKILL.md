# Finka UI Component Patterns

Use these pre-styled CSS classes or patterns (from `app/globals.css`) when constructing common UI blocks in Finka.

## Container
- **Site Container**: `.container-site` (Use for page wrapper sections to center content with consistent padding).

## Buttons
- **Primary Button**: Use `.btn-primary` for main actions.
- **Outline Button**: Use `.btn-outline` (light border on dark background) or `.btn-outline-dark` (dark border on light background) for secondary actions.

## Badges & Dividers
- **Price Badge**: `.price-badge`
- **Section Divider**: `.section-divider` (a small yellow accent bar under section headers).
